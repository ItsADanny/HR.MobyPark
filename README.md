## (EN)

### Description
This repo contains all the code for the MobyPark project from the Software Construction: Process & Tools course.

The main goal of this project is to make sure students learn about RESTFUL API's, CI/CD Pipeline implementation, Code Analysize and Code refactoring.

This project will be made with the requirements outlined in the Course manual that is included in this GitHub repo (Branch: Template, Document: INFSCP01 - 2526 - Full-time Course Manual - Definitief.pdf).
